# 植物診断ラボ — 一般公開向けバージョン

## できること

- アカウントや学校情報の入力なしで、トマトの全体写真から「株全体・葉・実」を判定します。
- JPEG/PNG、10MB以下の画像を検証してからモデルに送ります。
- AIの結果・助言・収穫進捗の目安を表示します。
- 実が写っていない写真では実モデルを動かさず、収穫進捗を「判定なし」にします。
- 写真・記録をサーバーのファイルへ保存しません（公開版では環境変数での保存有効化もできません）。

## 起動

Python 3.11を推奨します。メモリに余裕のあるLinux環境が必要です。

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 必須のAIモデル

以下6ファイルを `app.py` と同じフォルダーを基準に配置します。今回の配布ZIPにはすべて同梱しました。

```text
models/whole/keras_model.h5
models/whole/labels.txt
models/leaf/keras_model.h5
models/leaf/labels.txt
models/fruit/keras_model.h5
models/fruit/labels.txt
```

モデルがない場合は、安全のため診断ボタンが無効になります。提供されたラベル数とモデル出力数は照合済みですが、実推論と診断精度は未検証です。従来のTeachable Machine形式に合わせ、Python 3.11 / TensorFlow 2.15.1 / Keras 2を指定しています。

## 公開の前に

1. 学習済みモデル3組を入れる。
2. Python/Streamlit/TensorFlowが動くホスティングに配置し、HTTPSで公開する。静的HTML専用ホスティングでは動きません。
3. 実際のトマト画像を用いて精度、誤判定、処理時間、負荷を測る。
4. 利用規約・プライバシーポリシー・問い合わせ先を整備する。
5. インターネット公開後に大きなアクセスが来ても停止しないか試す。

**注意:** 匿名利用と引き換えに、結果の長期保存・端末間同期・ユーザーごとの履歴一覧は提供していません。履歴保存を公開する場合は認証・所有者チェック・DB等を別途設計してください。

### 写真テストの結果

提供されたトマト写真2枚（1536×2048ピクセル）は両方とも画像検査を通過し、224×224×3のモデル入力へ変換できました。写真には実が確認できないため、画面では「写っていない」を選ぶのが適切です。TensorFlow実行環境がないため、AIモデルによる予測値・分類精度は未確認です。テスト写真自体は本配布ZIPには含めていません。
