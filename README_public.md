# 🍅 植物診断ラボ（Tomato Diagnosis Lab）

植物診断ラボは、トマトの写真をAIで分析し、生育状態の確認や栽培管理を支援するWebアプリケーションです。

本プロジェクトはオープンソースとして公開しており、誰でもソースコードを閲覧・改良し、開発に参加できることを目指しています。

## 🌱 プロジェクトの目的

本プロジェクトでは、次の3つを目指しています。

- **植物の生育状態を手軽に確認すること**
- **利用者や開発者がアプリを自由に改良できること**
- **AIモデルや診断機能を継続的に改善すること**

プログラミング経験者、AI開発者、植物栽培に詳しい方など、さまざまな分野からの参加を歓迎します。

## 📱 アプリを使う

**一般公開版**

https://tomato-diagnosis-lab-9pty3t5dpdzszrt9dj78gi.streamlit.app/

アカウント登録なしでトマトの写真診断を利用できます。

## 🔍 主な機能

### AIによる写真診断

トマトの全体写真1枚を使用し、Teachable Machineで作成した3つのAIモデルで分析します。

- 株全体：良好な状態、葉の重なり、誘引の必要性など
- 葉：色や見た目の変化など
- 実：成長途中、成熟中、収穫間近など

診断結果に応じて、観察のポイントや栽培管理のアドバイスを表示します。

実が写っていない場合は実の診断を行いません。

### 栽培記録（開発中）

テスト版では、次の機能を実装・動作確認しています。

- メールアドレスによる登録・ログイン
- Googleアカウントによるログイン
- パスワード再設定
- 診断記録と写真の保存・表示
- 保存した記録の削除

これらは一般公開版への反映を進める予定です。一般公開版にすべて実装されていることを意味するものではありません。

## 💻 使用技術

- Python
- Streamlit
- TensorFlow / Keras
- Google Teachable Machine
- Pillow / NumPy
- Supabase（認証・データベース・画像保存のテスト版で使用）

## ⚙️ 開発環境の構築

Python 3.11を推奨します。

GitHubからリポジトリを取得します。

```bash
git clone https://github.com/yuika200-cmyk/tomato-diagnosis-lab.git
cd tomato-diagnosis-lab
```

必要なライブラリをインストールします。

```bash
python -m pip install -r requirements.txt
```

アプリを起動します。

```bash
python -m streamlit run app.py
```

ブラウザで表示されたローカルURLから利用できます。

### AIモデルの配置

次のファイルが必要です。

```text
models/
├── whole/
│   ├── keras_model.h5
│   └── labels.txt
├── leaf/
│   ├── keras_model.h5
│   └── labels.txt
└── fruit/
    ├── keras_model.h5
    └── labels.txt
```

必要なモデルが配置されていない場合は診断できません。

AIモデルの配布状況と利用条件については、リポジトリ内のファイルを確認してください。

## 🔐 セキュリティとデータの取り扱い

- Supabaseなどの認証情報や秘密鍵をGitHubに登録しないでください。
- 実際の利用者の診断記録や個人情報を開発用データとして公開しないでください。
- 画像やAIモデルを再配布する際は、それぞれの利用条件を確認してください。
- 開発した機能は、本番環境に反映する前に十分にテストしてください。

一般公開版では診断履歴を長期保存する機能を提供していません。テスト版の栽培記録機能では、登録した利用者の記録をSupabaseで管理しています。

## ⚠️ AI診断について

AIの判定結果は参考情報であり、植物の病気や栄養状態、収穫時期を確定するものではありません。

診断精度は今後も検証・改善していく必要があります。
